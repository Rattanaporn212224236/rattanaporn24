# ระบบผู้ดูแล (Admin Web) - แจ้งข่าวสารและกิจกรรม คณะ วว. มก.ฉกส.

โปรเจกต์นี้มี 2 ส่วนรันคู่กัน:
- **Frontend**: React + Vite (โฟลเดอร์ `src/`)
- **Backend API**: Express + MySQL (โฟลเดอร์ `server/`) เชื่อมกับฐานข้อมูล `kuse_event`

## เริ่มต้นใช้งาน

1. ติดตั้ง dependency (ครั้งแรกครั้งเดียว):
   ```
   npm install
   ```

2. เปิด XAMPP แล้ว Start Apache + MySQL จากนั้น import ไฟล์ `kuse_event.sql` เข้า phpMyAdmin
   (ถ้ายังไม่เคย import)

3. ตรวจสอบไฟล์ `.env` (มีให้แล้ว ค่าเริ่มต้นตรงกับ XAMPP ทั่วไป: user `root`, ไม่มีรหัสผ่าน)
   ถ้า MySQL ของคุณตั้งรหัสผ่านไว้ ให้แก้ `DB_PASSWORD` ในไฟล์ `.env`

4. รันทั้งสองฝั่งพร้อมกันด้วยคำสั่งเดียว:
   ```
   npm run dev:all
   ```
   - หน้าเว็บแอดมิน: http://localhost:5173
   - API server: http://localhost:5000

   (หรือจะรันแยกสองหน้าต่างก็ได้: `npm run dev` สำหรับเว็บ และ `npm run server:dev` สำหรับ API)

5. ครั้งแรกที่ API server รัน จะ "ซ่อม" ข้อมูลเก่าจากไฟล์ SQL ให้อัตโนมัติ (ดูข้อความใน terminal):
   - แปลงรหัสผ่านผู้ใช้ (เดิมเป็น plain text) ให้เป็น bcrypt hash
   - แก้ปี พ.ศ. ที่หลงอยู่ในคอลัมน์วันที่ของกิจกรรมให้เป็น ค.ศ.
   - แก้สถานะกิจกรรมที่ว่างเปล่าให้ถูกต้อง

## บัญชีทดสอบ (รหัสผ่านเดิมทุกบัญชีคือ `123456`)

| Username     | สิทธิ์      | หน่วยงาน                            |
|--------------|-------------|--------------------------------------|
| `superadmin` | Super Admin | ส่วนกลาง (เห็น/จัดการได้ทุกหน่วยงาน) |
| `cpe_dept`   | Admin       | ภาควิชาวิทยาการคอมพิวเตอร์ฯ          |
| `smo_club`   | Admin       | สโมสรนิสิตคณะ วว.                    |

## สิทธิ์การใช้งานตามขอบเขตโครงงาน

- **Super Admin**: จัดการสิทธิ์ผู้ใช้งาน (เพิ่ม/ระงับ/ลบ/รีเซ็ตรหัสผ่านแอดมิน), จัดการข้อมูลหลัก (หลักสูตร/ภาควิชา/หน่วยงาน/สโมสร), สร้าง-แก้ไข-ลบกิจกรรมได้ทุกหน่วยงาน, แดชบอร์ดภาพรวมทั้งคณะ
- **Admin (หน่วยงาน)**: สร้าง-แก้ไข-ลบ-เปลี่ยนสถานะกิจกรรมได้เฉพาะหน่วยงานตัวเอง, แดชบอร์ดเฉพาะหน่วยงานตัวเอง, จัดการบัญชีตัวเอง (อีเมล/รหัสผ่าน)

## หมายเหตุเกี่ยวกับ "ข้อมูลหลัก" (Master Data)

เอกสารขอบเขตระบุให้จัดการ หลักสูตร/ภาควิชา/หน่วยงาน/บุคลากร/สถานที่ แต่ฐานข้อมูล `kuse_event.sql`
ที่ใช้จริงมีเพียงตาราง `categories` + `departments` (ไม่มีตารางบุคลากร/สถานที่แยกต่างหาก) ระบบนี้จึงจัดการ
เฉพาะหลักสูตร/ภาควิชา/หน่วยงาน/สโมสรนิสิต ผ่านตาราง `departments` ตามที่มีอยู่จริง หากต้องการขยายให้ครบ
ตามเอกสาร จะต้องออกแบบตารางเพิ่มเติมสำหรับบุคลากรและสถานที่ในอนาคต

## โครงสร้างโฟลเดอร์ที่สำคัญ

```
backend/
├── server/                # Express API (ใหม่)
│   ├── config/            # เชื่อมต่อฐานข้อมูล + สคริปต์ซ่อมข้อมูลตอน boot
│   ├── controllers/       # logic ของแต่ละ endpoint
│   ├── middleware/        # ตรวจสอบ JWT / สิทธิ์ / อัปโหลดไฟล์
│   ├── routes/            # กำหนดเส้นทาง API
│   └── uploads/events/    # ไฟล์รูปภาพกิจกรรมที่อัปโหลด
├── src/                   # React (หน้าเว็บแอดมิน)
│   ├── api/client.js      # ตัวกลางยิง request ไปหา backend
│   ├── context/AuthContext.jsx
│   └── pages/             # Login, Dashboard, MainData, CreateEvent, EventList, UserManagement, AccountSettings
└── .env                   # ค่าตั้งค่าฐานข้อมูล/พอร์ต/JWT
```
