# สรุปสำหรับผู้ดูแลเซิร์ฟเวอร์แอปมือถือ: คอลัมน์ `registration_link`

## ที่มา
กิจกรรมบางงาน (เช่น รับสมัครสตาฟ, งานที่จำกัดจำนวนคน) ต้องการให้ผู้สนใจ "ลงทะเบียน" ล่วงหน้า ต่างจากกิจกรรม
แบบเชิญชวนทั่วไปที่กดเข้ามาอ่านรายละเอียดอย่างเดียวก็พอ เว็บแอดมินไม่ได้สร้างระบบลงทะเบียน/นับจำนวนผู้สมัครเอง
(เพื่อไม่ให้ขอบเขตงานบวมเกินจำเป็น) แต่ให้แอดมินแปะ "ลิงก์ลงทะเบียนภายนอก" ไว้แทน (เช่น Google Form, Line)

## คอลัมน์ที่เพิ่มในตาราง `events`
```sql
registration_link VARCHAR(500) NULL   -- อยู่ต่อจากคอลัมน์ responsibilities
```
- ถ้า `NULL` หรือว่าง = กิจกรรมแบบเชิญชวนทั่วไป ไม่ต้องลงทะเบียน
- ถ้ามีค่า = เป็นลิงก์ http(s) ที่แอดมินกรอกไว้ (ผ่านการตรวจแล้วว่าขึ้นต้นด้วย http:// หรือ https://)

## สิ่งที่แนะนำให้ทำฝั่งแอปมือถือ
ที่หน้ารายละเอียดกิจกรรมของนิสิต ถ้า `registration_link` ไม่ว่าง ให้แสดงปุ่ม/ลิงก์ "ลงทะเบียนเข้าร่วม" ที่เปิดลิงก์นั้น
(เช่นเปิดในเบราว์เซอร์ในตัวแอป หรือเปิดแอปภายนอกตามชนิดลิงก์) ถ้าว่างก็ไม่ต้องแสดงปุ่มนี้เลย

เช่นเดียวกับ `department_links` — มีข้อมูลในฐานข้อมูลให้แล้ว แต่ต้องแก้โค้ดฝั่งแอปมือถือเองถึงจะเห็นผลจริง
(คนละเซิร์ฟเวอร์ คนละโค้ด แชร์แค่ฐานข้อมูล)
